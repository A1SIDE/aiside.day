# Contributing to AISIDE

Thanks for helping make AISIDE more useful. Feedback in English or Chinese is welcome.

This is AISIDE's public community and updates repository. The website's application source code is not included.

## Send useful feedback

[Search existing issues](https://github.com/A1SIDE/aiside.day/issues) first. If someone has already reported the same issue, add useful details there or use a reaction to show interest.

[Open an issue](https://github.com/A1SIDE/aiside.day/issues/new/choose) using the form that fits:

- **Bug report:** include the page, steps to reproduce and the expected result.
- **Feature request:** describe the task you want to accomplish and the obstacle.
- **Content correction:** identify the passage and provide public evidence for the correction.
- **Research request:** suggest a product or business question and explain why it is worth exploring.

Keep one topic per issue. Remove personal information, access tokens and payment details from screenshots and logs. Please keep discussion constructive and relevant to AISIDE.

## Improve these public documents

Pull requests for broken links, typos, translations and clearer feedback instructions are welcome. For a larger change, open an issue first to explain the intended improvement. Application code changes cannot be submitted here because the website's source code is not part of this repository.

A suggestion or pull request is not a commitment to ship a feature or publish a report. Confirmed changes are shared through [Releases](https://github.com/A1SIDE/aiside.day/releases) and the [website changelog](https://aiside.day/en/changelog).

## 中文说明

欢迎用中文提交问题、功能建议、内容纠错和研究选题。提交前请搜索已有 Issue；每个 Issue 尽量只讨论一个主题，并提供页面链接、复现步骤或参考来源。截图和日志请隐藏隐私信息。

这里是 AISIDE 的公开社区与更新仓库，不包含网站应用源码。欢迎改进本仓库的文档、链接和翻译；建议是否采纳及发布时间以实际更新为准。
