# Help and feedback

Visit [AISIDE](https://aiside.day/en) to browse product research and AI business cases. 中文网站：[aiside.day/zh](https://aiside.day/zh)。

| You want to… | Start here |
| --- | --- |
| Report a website problem / 反馈网站问题 | [Bug report](https://github.com/A1SIDE/aiside.day/issues/new?template=bug_report.yml) |
| Suggest an improvement / 提出功能建议 | [Feature request](https://github.com/A1SIDE/aiside.day/issues/new?template=feature_request.yml) |

| Ask another product question / 其他产品问题 | [Open an issue](https://github.com/A1SIDE/aiside.day/issues/new/choose) |

English and Chinese are welcome. Search [existing issues](https://github.com/A1SIDE/aiside.day/issues) before opening a new one.

Issues are public. Do not include passwords, access tokens, private account information or payment details. Keep account-specific information out of public reports.

GitHub hosts the community and release notes; the AISIDE website is used to access the product. This repository does not include the website's application source code.
